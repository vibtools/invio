# Invio v1.0.0.1.13

## P04 Verification & Correction

This release re-audits the exact shipped `v1.0.0.1.12` P04 baseline against the approved Customer Data Contract and Import Upgrade plan. It does not begin P05 or change the production phase count.

### Corrected

- Restored the historical mutable-list behavior of `CustomerList.emails` while retaining `CustomerRecord` as the authoritative customer representation.
- Preserved source row numbers through the import-to-state merge boundary so conflicts against existing Customer List metadata remain row-numbered.
- Restricted explicit country values to two ASCII alphabetic characters; country remains optional and is never guessed.
- Converted malformed workbook/parser failures into the existing caught customer-import error boundary instead of allowing parser exceptions to escape the UI workflow.
- Reverted the unrelated Dashboard customer metric-label wording changed in v1.0.0.1.12 outside the approved P04 Customer Lists UI scope.

### Unchanged

- SQLite schema remains v3.
- Stripe customer lookup/create/send remains email-based.
- Refrens normal Task execution remains disabled until P11.
- Customer Lists remain live-mutable after Task creation until P05.
- ProviderManager, WorkerManager, Account/Invoice/Task models, provider manifests, shared UI design system, and dependency set are unchanged.

Production progress remains **4/14 phases complete**. The next separately approved phase is **P05 - Immutable Task Execution Snapshot and Input Consistency**.
