# Invio v1.0.0.1.46.0 — Custom Window Chrome

Parent baseline: `v1.0.0.1.45.0`.

## Root cause

The white bars were operating-system native non-client frames because MainWindow and app-owned QDialogs used standard framed window flags. Their colors/layout are outside Invio QSS control.

## Scope implementation

- Main Window: `Qt.WindowType.FramelessWindowHint` + compact `MainTitleBar` with app icon, Invio, current context, Vib Tools, minimize, maximize/restore and close.
- App-owned dialogs/message boxes: frameless + compact `DialogTitleBar` with icon, title and close.
- Frameless edge resizing and title-bar dragging delegate to `QWindow.startSystemResize` / `startSystemMove` where available, with movement fallback.
- Native file dialogs are unchanged.
- Dialog content, callbacks, modal semantics and all non-title-bar UI/runtime behavior are unchanged.

Version mapping: app `1.0.0.1.46.0`, PE `1.0.1.4600`, MSI `1.1.4600`.
