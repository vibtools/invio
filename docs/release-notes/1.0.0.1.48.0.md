# Invio v1.0.0.1.48.0

Parent Official Baseline: `v1.0.0.1.47.0`.

This scope-locked UI correction changes only Main/Dialog custom chrome and app-owned dialog title presentation. It adds a compact **right margin** after the Close control on both title bars, adds a very light dialog border plus **subtle shadow** separation from the dimmed parent surface, and removes form-dialog **title duplication** so the custom `DialogTitleBar` is the single dialog title.

No dialog fields, field order, validation, footer actions, Data Grid behavior, navigation, provider/runtime/storage/task/customer/invoice/settings behavior, dependency, schema, or business logic changes are included.

Version mapping: application `1.0.0.1.48.0`, PE `1.0.1.4800`, MSI `1.1.4800`.
