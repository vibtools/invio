# Invio v1.0.0.1.41 — Providers Page Compact UI/UX Candidate

Parent Official Production Baseline: **v1.0.0.1.40.2**.

## Approved UI changes

- Providers Page root background and 14px page padding remain unchanged.
- Provider grid uses 16px row/column gaps and reflows across 2–4 columns from a 280px minimum card width.
- Provider cards are fixed at 220px height with 16px internal padding.
- Card header: neutral 32x32 provider-initial placeholder, provider title/version, right-aligned Installed/Available badge.
- Description: maximum three visible lines with right ellipsis and full tooltip.
- Metadata: effective runtime capabilities as compact chips plus one runtime-adapter/credential-count line.
- Install/Uninstall action remains the existing real callback and is anchored to the bottom with stretch.
- Hover surface changes from `#111722` to `#1A212E`; border remains the normal `#1E2633` contract.
- Load Provider keeps the same trusted-code workflow and receives only compact provider-page-specific emphasis.

## Explicitly unchanged

ProviderManager, ProviderRuntime, P13 external adapter interface, Stripe, Refrens, Agiled, Odoo, Accounts, Tasks, Invoice Templates, Customer Lists, Reports, Live Logs, Settings, SQLite schema v5, CredentialStore, WorkerManager, runtime dependencies, provider manifests and provider business/API behavior are unchanged.
