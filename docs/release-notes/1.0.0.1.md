# Invio 1.0.0.1

Release date: 2026-08-07

## Approved scope

This release contains only Update-001 and directly required release/audit documentation:

- Fix the sidebar background color using the official Vib Tools desktop sidebar contract.
- Correct the Providers page card presentation using the official Vib Tools Plugin Page design contract.
- Remove development-stage/UI-only product markings from current production-facing application surfaces.
- Preserve all existing pages, provider contracts, workflows, functions, task threading behavior, and application features.

## UI changes

### Sidebar

The sidebar scroll area, viewport, and navigation host now explicitly use `#090D14`, matching the official Vib Tools validation application and preventing the Windows platform palette from rendering the navigation surface as light gray/white.

### Providers page

Provider cards now use the official compact plugin-card anatomy and tokens:

- surface `#111722`;
- border `#1E2633`;
- 13 px semibold title;
- compact 11 px description;
- `#1E293B` version/category-style chip;
- existing Available/Installed status treatment;
- existing primary Install action.

No provider search, category filtering, Details action, marketplace behavior, or other feature from the validation reference application was added.

## Production-facing cleanup

Current runtime labels no longer describe Invio as a UI-only or pre-production application. Unsupported provider operations remain explicitly unavailable; the release does not simulate API verification or sending.

## Compatibility

No page, provider ID, credential key, account mode, declared capability, task API, worker-manager contract, or domain behavior was renamed or removed.
