# Invio v1.0.0.1.5

## Scope

This release is a scope-locked Invoice Template UI repair over the frozen `v1.0.0.1.4` baseline. No template field, provider/task execution behavior, currency catalog, account/customer model, worker architecture, dependency, or unrelated page was changed.

## Fixed

- Removed Invoice Template card-level vertical `QSizePolicy.Maximum` overrides that allowed compact `QScrollArea` resizing to compress cards below their required content height.
- Added Invoice-Template-local wrapped-label sizing using minimum vertical policy and height-for-width behavior.
- Added Invoice-Template-local form groups that preserve minimum content height without modifying the shared application form helper.
- Moved Currency and Invoice Type guidance into dedicated full-width rows so narrow Currency geometry cannot force helper text into the next control.
- Replaced the raw upper sub-layout insertion with a minimum-height host widget and top-aligned cards.
- Applied a minimum-size layout constraint to the scroll content host so compact-window pressure produces scrolling rather than control/text compression.
- Top-aligned secondary and invoice-item cards while leaving the terminal stretch to absorb unused viewport height.
- Fixed Invoice Note, Customer Note, Footer, and Terms editors at the existing compact 52 px intended height so they cannot collapse under scroll-layout pressure.

## Compatibility

Currency type-to-search, template validation, template payloads, provider mappings, task binding, Stripe/Refrens runtime behavior, and all non-template pages remain unchanged.
