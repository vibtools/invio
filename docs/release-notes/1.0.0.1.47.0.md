# Invio v1.0.0.1.47.0

Parent Official Baseline: `v1.0.0.1.46.0`.

This release candidate is **UI/UX only** and applies the owner-approved Vib Tools desktop design-system refinement. It removes the redundant second application header, groups the existing navigation under compact sidebar sections with packaged SVG icons, standardizes app-owned dialog chrome/body/footer/modal presentation, centralizes shared control states and inline verification feedback, and keeps the existing Accounts, Customer Lists, Invoice Templates, Data Grid and backend workflows intact.

No provider API, database, task execution, customer processing, invoice generation, Settings persistence, dependency, schema, or business-logic change is included.
