# Invio v1.0.0.1.41.1 — Providers Page Final UI Polish

Official Parent Baseline: **Invio v1.0.0.1.41**.

This hotfix is limited to the owner-requested Providers Page final visual polish. Provider runtime/API behavior is unchanged, including ProviderManager install/load/uninstall callbacks, P13 external-adapter trust/execution semantics, Stripe/Refrens/Agiled/Odoo provider behavior, SQLite schema v5, WorkerManager/QThread ownership, Tasks, Accounts, Settings and dependencies.

## Providers Page changes

- Adds a live Search providers field immediately above the provider card grid.
- Replaces v1.41 neutral provider-initial placeholders with packaged provider logo assets for Stripe, Refrens, Agiled and Odoo and increases the rendered logo size from 32px to 40px.
- Moves provider package status directly below the logo. Installed packages are presented with the owner-approved `Verified` badge; non-installed bundled packages remain `Available`.
- Moves the provider version to the bottom-right card footer in a small muted text treatment.
- Removes visible runtime-adapter/credential-count metadata from Provider cards.
- Removes visible capability chips from Provider cards.
- Keeps the bottom-anchored Install/Uninstall action behavior. Providers-page Uninstall now uses the existing primary blue theme instead of the global danger/red treatment.
- Retains the v1.41 220px fixed card height, 280px minimum width, 16px card/grid spacing, 2–4 responsive columns, three-line description ellipsis and `#1A212E` hover surface.

## Packaged visual resources

The runtime distribution now carries provider logo PNG resources under `assets/icons/providers/`. Wheel and Windows portable release audits explicitly require those four files so a release cannot silently omit the approved provider-card logos.
