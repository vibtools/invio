# Invio v1.0.0.1.43.0 — Global Data Tables + Lists + Fonts

**Official Parent Baseline:** Invio v1.0.0.1.42.0  
**Scope:** compact Data Grid UI/UX only  
**Runtime/business scope:** unchanged

## UI changes

- Adds reusable compact Data Grid toolbar/footer helpers for UI-session search, derived filters and in-memory pagination.
- Uses 28px Data Grid search/filter/pagination controls, 28px table headers and 30px rows.
- Keeps Segoe UI Variable/Segoe UI; data pages use the approved 400/500 hierarchy while table headers remain 11px/600.
- Enables subtle alternating rows, restrained hover/selection states, no vertical grid lines and full-value tooltips.
- Adds semantic compact status badges for success/danger/warning/neutral data states without changing the underlying status values.
- Accounts keeps `QTreeWidget` grouping, adds 16px provider logos, stronger provider-row hierarchy and compact displayed API-test timestamps.
- Customer Lists and Customer Records gain independent search/filter/pagination and consistent SelectRows behavior.
- Invoice Templates gains search/filter/pagination and fixes the clipped Actions column with the approved 80px compact layout.
- Both Reports tables use the same `#111722` / 8px surface, with search/filter/pagination, numeric alignment and semantic status presentation.
- Invoice Items gains view-only search/pagination while the complete editable row set remains authoritative for template save.
- New Task Accounts is the only widget-type conversion: `QListWidget` -> four-column `QTableWidget`, with search/filter/pagination and a 250px maximum compact height while preserving Verified/reservation gates.
- Adds `assets/icons/search.svg` and includes it in wheel/portable resource audits.

## Explicitly unchanged

- ProviderManager, ProviderRuntime and provider API/send behavior.
- Odoo, Stripe, Refrens and Agiled execution contracts.
- P13 external-provider interface and trusted-code workflow.
- SQLite schema v5, CredentialStore and WorkerManager/QThread architecture.
- Task state/retry/snapshot/delivery-ledger semantics.
- Customer import/business rules, Invoice calculation/provider mapping, Reports data meaning.
- Settings persistence/defaults, approved v1.42.0 Global Forms/Settings UI and approved v1.41.1 Providers UI.
- Runtime dependencies and CI/release topology.
