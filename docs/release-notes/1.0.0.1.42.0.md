# Invio v1.0.0.1.42.0 — Global Forms + Settings UI/UX Refinement

**Official Parent Baseline:** Invio v1.0.0.1.41.1  
**Scope:** Global Forms + Settings Page presentation only

## Approved UI changes

- Adds scoped compact form tokens for application-owned dialogs and Settings: 32px controls, 6px radius, softened title/body/muted/placeholder text colors.
- Normalizes application-owned dialog root padding to 12px and layout spacing to 8px.
- Removes verbose dialog subtitles and nonessential help captions from New Customer List, Add/Edit Account, Re-test Account, Invoice Template and New Task.
- Replaces platform-order `QDialogButtonBox` footers in create/save dialogs with explicit right-aligned secondary + PrimaryButton actions.
- Adds Settings Search with `Ctrl+F` focus and live matching by card/option keywords.
- Keeps Settings responsive at two columns when space permits and one column when narrow; Customer Defaults spans the two-column row and uses compact inline fields.
- Renames Restore Defaults to Reset Settings without changing its behavior: defaults are loaded into the UI and persist only after Save Changes.
- Removes all five Settings card subtitles/help paragraphs while preserving every setting key, default and persistence rule.

## Frozen behavior

No provider/runtime/API, P13, SQLite schema v5, CredentialStore, WorkerManager/QThread, Task/customer/invoice business behavior, Providers Page, dependency or settings persistence changes are included.
