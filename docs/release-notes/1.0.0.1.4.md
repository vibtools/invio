# Invio v1.0.0.1.4

Baseline: `v1.0.0.1.3`

This release is limited to the approved Settings and Invoice Template UI corrections.

## Fixed

- Settings no longer exposes a platform-default white/light background below its cards; the scroll viewport and content host use the frozen Vib Tools dark page background.
- Invoice Template no longer exposes white/light gaps between sections; the dialog viewport/content host use the same dark background.
- Invoice Template cards no longer absorb spare scroll-viewport height, preventing stretched/broken spacing around Footer, Terms, Provider Options, and Invoice Items.
- Currency and Days until due are rebalanced so Currency is slightly narrower and the row reads as one compact form.

## Currency search

Currency remains backed by the same approved uppercase catalog. The control is now editable with case-insensitive contains completion, no arbitrary insertion, and at most eight visible suggestions. Saving validates the typed code against the approved catalog before the existing template/provider/task pipeline receives it.

## Scope protection

No invoice-template field, provider adapter, provider manifest, account/customer/task model, worker-thread boundary, sending operation, page, dependency, or workflow was removed, renamed, replaced, or expanded.
