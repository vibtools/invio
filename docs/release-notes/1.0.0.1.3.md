# Invio v1.0.0.1.3

Released: 2026-08-07
Baseline: v1.0.0.1.2

This scope-locked release adds the Dashboard, updates the Invoice Template editor/model, binds templates to Tasks, introduces built-in packaged-provider execution, fixes Settings typography/checkmarks, and compacts Live Logs/Reports using the supplied Vib Tools reference screens.

Stripe task execution now creates, finalizes, and sends provider invoices through the existing per-task worker thread. Refrens API functions are implemented, but normal task execution is blocked before invoice creation because Refrens requires customer country and the approved Customer List model contains email only. No billing country is guessed.

No existing page/feature was removed or renamed, no provider manifest schema was changed, no customer/billing/shipping/payment fields were added to invoice templates, no account-reservation rule was changed, and no dependency was added.
