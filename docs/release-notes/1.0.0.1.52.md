## Changes in this release

- Website-issued RSA license system: activation against invio.vib.tools, local signature-verified/tamper-resistant caching, and a periodic (startup + every 12h) server re-check so an admin-side ban/expiry/HWID reset actually reaches an already-activated desktop.
- License gate wired into `ExternalAdapterRegistry.reload_installed()`: unlicensed external providers register as `Unlicensed` and are blocked from Accounts/Task use before their adapter code loads.
- `LicenseActivationDialog` and license status UI (License/Re-license button, Licensed badge) on the Providers page.
- Online Provider Catalog: fetch the public provider catalog from invio.vib.tools and download+checksum-verify a provider's `.ivx`, feeding the existing `import_ivx`/`install_packaged` pipeline.
- Providers page redesign: scrollable layout, 3-column grid, Settings-page-matching background/card styling, fixed card-overlap bug.
- Three additional reference provider packages: QuickBooks Online, Zoho Books, Zoho Invoice.
- Added the `cryptography` dependency (RSA signature verification) and repinned the Linux CI constraint's transitive `cryptography` version to stay within the declared `<50` range.
- Advance release identity to application/wheel `1.0.0.1.52`, PE `1.0.1.52`, MSI `1.1.52`, and tag `v1.0.0.1.52`.
