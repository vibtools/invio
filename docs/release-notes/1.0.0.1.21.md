# Invio v1.0.0.1.21

## Pre-P08 Provider Adapter Foundation and Agiled Package

`v1.0.0.1.21` is an explicitly approved pre-P08 provider/API architecture exception built on the verified `v1.0.0.1.20` baseline. It removes built-in provider capability/runtime dispatch duplication by introducing one internal provider adapter contract registry while preserving existing Stripe/Refrens behavior.

### Added

- Internal `ProviderAdapterContract` registry for packaged provider runtime binding.
- Registry-backed capability profile and manifest/runtime contract lookup.
- Registry-backed API Test and Task batch dispatch in `ProviderRuntime`.
- Packaged `Agiled` provider manifest with protected `API Key` credential entry and declared invoice/send/API-test capabilities.
- Agiled contract regression tests proving that no API key or invoice request is transmitted while the official API contract remains unresolved.

### Agiled fail-closed boundary

Agiled's current official API product page documents scoped API keys and Bearer-token authentication, but its linked official API documentation currently exposes a different legacy contract using `https://my.agiled.app/api/v1/`, `api_token` query authentication and a required `Brand` header. The user-supplied `https://api.agiled.ai/public/v1` base URL and an explicit current invoice-send API operation are not confirmed by the accessible official API reference.

For that reason `v1.0.0.1.21` intentionally reports **no executable Agiled runtime capability**. Agiled API Test and Task invoice sending fail closed before network transport; the API key is not transmitted to a guessed endpoint.

### Preserved

- Stripe API Test and Stripe invoice create/finalize/send semantics.
- Refrens API Test and the existing P11 production Task execution gate.
- P05 immutable execution snapshots and `Task.id` logical run identity.
- P06 preflight and packaged-manifest integrity behavior.
- P07 Task state/resend safety.
- WorkerManager and one-QThread-per-active-Task architecture.
- SQLite schema v4, persistence, credentials and dependencies.
- Existing external injected-runner API; no arbitrary external Python plugin loading is introduced.
- P08/P09+ behavior remains unimplemented.

### Verification

- Parent `v1.0.0.1.20` suite: **230/230 PASS**.
- `v1.0.0.1.21` suite after adapter/Agiled coverage: **237/237 PASS** before final documentation packaging.
- No live Agiled API certification is claimed because the current official contract is internally inconsistent and no owner API key was supplied to this build environment.
