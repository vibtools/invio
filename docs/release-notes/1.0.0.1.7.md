# Invio v1.0.0.1.7

## Scope

Corrective verification release for **P01 - Real Account API Verification** only. Parent baseline: exact uploaded `v1.0.0.1.6` full artifact.

## Verified P01 behavior

- Add Account executes Stripe/Refrens API verification through the existing `ProviderRuntime`.
- Verification executes on the existing P01 dialog-owned `QThread`, not the GUI thread.
- Stripe API Test enforces selected Test/Live mode before provider permission requests.
- Successful verification creates current-session account status `Verified`.
- Provider/mode/credential changes invalidate the previous verification.
- Providers without executable API-test adapters remain unavailable for API Test.
- New Task, backend Task creation, Start, and Retry reject unverified accounts.
- API-test provider errors are credential-value scrubbed before user/log presentation.

## Corrected defects found during re-audit

1. The supplied full `v1.0.0.1.6` artifact contained a stale ignored `providers/registry/refrens.json` with `1.0.3-ui` and deferred-backend wording. The shipped registry state is synchronized to the packaged Refrens manifest in this corrective delta.
2. The runtime-surface production-marker test scanned all JSON files under `providers/`, including mutable Git-ignored registry state. It now audits source plus bundled provider packages, which are release-controlled surfaces.
3. The release metadata test method name still referenced an older release identifier. It is corrected for `v1.0.0.1.7`.
4. The `v1.0.0.1.6` final verification record stated 62/62 passing tests, while the exact later-uploaded full artifact runs 61/62 before correction. Historical records now include a truthful post-release correction note.

## Unchanged

No provider ID, credential field, account mode, provider API-test semantics, invoice-send behavior, task worker architecture, Customer List/Invoice Template model, persistence mechanism, page/UX design, or dependency is changed by this release.

P01 remains the only completed production implementation phase. P02 remains pending separate owner approval.
