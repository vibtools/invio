## Why this release exists

GitHub Actions run `31371279808` tested commit `12ef4800a75a993da3899399882f0e44daccd4df` from the v1.35 distribution update. Both Ubuntu and Windows failed at the regression audit before wheel/Nuitka/WiX packaging could execute.

The primary root cause was repository publication, not the distribution algorithms themselves: the existing `.gitignore` rule `build/` also matched the intentional source directory `scripts/build/`. The v1.35 source baseline contained the approved helper scripts, but `git add -A` omitted them from the GitHub commit. Tests then failed to import `finalize_release_checksums.py` and could not open `prepare_windows_distribution.py`.

Windows also exposed two handle-lifetime defects. The P14 subprocess crash-recovery test used `sqlite3.connect()` as a context manager for its verification query; Python commits/rolls back that context but does not close the connection, so Windows could keep the temporary database locked during cleanup. Separately, `DomainStore._connect()` could leave a successfully opened SQLite handle unclosed if setup raised before the connection was returned, which was visible in the corrupt-database regression as `WinError 32`.

## Corrections

- `.gitignore` now explicitly re-includes `scripts/build/`, its Python helpers and `.gitkeep`, while generated root `build/` and `dist/` remain ignored.
- The four existing v1.35 distribution helpers are re-published unchanged for GitHub reconciliation:
  - `version_info.py`
  - `prepare_windows_distribution.py`
  - `generate_wix_source.py`
  - `finalize_release_checksums.py`
- The P14 crash-recovery test explicitly closes its direct SQLite verification connection.
- `DomainStore._connect()` explicitly closes a partially initialized SQLite connection before preserving the existing operational/corruption error classification.
- Regression contracts verify that the approved `scripts/build` helper source is present and explicitly trackable.
- Workflow/application version identity advances to `1.0.0.1.36`; PE version is `1.0.1.36`; MSI version mapping is `1.1.36`.
