# Invio v1.0.0.1.17

## P06 - Provider Capability and Preflight Validation

This release completes P06 on the verified v1.0.0.1.16 baseline.

### Added

- Local no-side-effect provider preflight before New Task persistence and before Start/Retry runner creation.
- Packaged manifest/runtime capability reconciliation and Providers-page declared/runtime capability visibility.
- Reserved packaged provider IDs (`stripe`, `refrens`) against external-manifest replacement.
- Account verification-health/mode/credential validation at preflight.
- Stripe `INVOICE`-only, Automatic Tax, line-tax and currency safety checks based on the current executable Invio adapter contract.
- Canonical Refrens `https://api.refrens.com` endpoint trust enforcement before authentication payload construction.

### Preserved

- SQLite schema v4 and P05 immutable snapshots.
- WorkerManager one-QThread-per-active-Task architecture.
- Existing external `register_task_runner(provider_id, runner)` API.
- Provider manifests and dependency versions.
- Stripe customer/invoice/finalize/send implementation except preflight safety gates and release User-Agent marker.
- Refrens normal Task execution remains disabled until P11.
- P07+ behavior is not implemented by this release.

### Production roadmap

Production implementation progress: **6/14 phases complete**. Next phase: **P07 - Task State Machine and Resend Safety**, separately approval-gated.
