# Invio v1.0.0.1.44.0 — Intro/Subtitle Cleanup

**Official Parent Baseline:** Invio v1.0.0.1.43.0

## Scope

This candidate removes only static introductory descriptions and subtitles from application page headers and shared card/section surfaces, plus the static Task-card subtitle identified by the owner screenshots. Titles, field labels, dynamic status/validation/help required for operation, provider package body descriptions, data values, tables/lists, Search/Filter/Pagination, layout geometry, colors, fonts, backend/runtime behavior and workflows remain unchanged.

## Implementation boundary

- `page_header()` keeps its frozen signature but no longer renders the `description` argument.
- `card()` keeps its frozen signature but no longer renders the static `description` argument.
- The Task-card line `Independent provider task with dedicated account reservation and worker-thread slot.` is removed.
- Provider card package descriptions remain visible because they are provider content, not page/card intro subtitles.
- Dashboard dynamic `Next Step` guidance remains visible because it is runtime/user-state content, not static intro copy.

## Version mapping

- Application: `1.0.0.1.44.0`
- PE: `1.0.1.4400`
- MSI: `1.1.4400`
- Future tag: `v1.0.0.1.44.0`

## Compatibility

No persistence key, schema, provider API, plugin interface, worker/thread, Task transition, invoice/customer logic, dependency, page architecture, data-grid behavior, Settings behavior or Providers behavior changes are included. SQLite remains schema v5 and P13 remains interface v1.
