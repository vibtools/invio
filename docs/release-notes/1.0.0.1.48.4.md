# Invio v1.0.0.1.48.4

## Scope

**Compact Add Task Modal UI Redesign** over the frozen `Invio v1.0.0.1.48.3` baseline. Only the Tasks-page `NewTaskDialog` layout is changed.

## Root cause

The baseline modal stacked Provider, an Accounts label, the account search/filter toolbar, selectors and the action footer as separate vertical sections. The shared `DataGridToolbar` also rendered Search before its filters, while the account table height shrank dynamically to the current page's visible-row count. The result was unnecessary vertical whitespace and a tall composition that did not match the approved compact modal. The Task validation, selection, payload and backend creation path were already functional and were not the cause.

## Update

- Provider + account filters + account search are composed on one compact row.
- The existing checkbox account table remains directly below the toolbar with `ACCOUNT NAME`, `MODE` and `STATUS` columns unchanged.
- The existing account pager is preserved.
- The account grid uses the existing 250px maximum as a stable viewport and scrolls vertically when rows exceed the visible area.
- Invoice Template + Customer List + Cancel + Create Task are composed on one compact bottom row.
- Existing custom dialog title bar, application icon, close control, colors, typography, borders and restrained dialog shadow remain unchanged.
- Existing provider selection, availability/status filtering, search, checkbox state, account eligibility, invoice/customer selectors, validation messages, `payload()` keys, Cancel and Create Task callbacks remain unchanged.

## Runtime regression coverage

The existing real PySide6 interaction module now also covers New Task open/close/reopen lifecycle, provider changes, filtering, searching, account selection, account-grid vertical scrolling, Invoice Template and Customer List selection, Cancel and Create Task acceptance/payload. These tests execute in dependency-installed CI and skip only when PySide6 is not installed in the local forensic environment.
