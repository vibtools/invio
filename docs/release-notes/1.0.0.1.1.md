# Invio 1.0.0.1.1

Release date: 2026-08-07

## Approved scope

This release uses the fully reconstructed `v1.0.0.1` state as its baseline and changes only Settings-related UI, Settings-related backend behavior, directly required runtime wiring, tests, version metadata, and synchronized Markdown documentation.

## Settings UI

The existing Settings page now provides non-technical controls for current application behavior:

- fixed startup page or Last page used;
- optional window size/position memory;
- independent confirmation prompts for active-task exit, task close, invoice-template deletion, customer-list deletion, and Live Logs clearing;
- Live Logs timestamps, automatic scrolling, and optional maximum line retention;
- default file folder and optional last-used-folder memory;
- Restore Defaults and Save Changes actions with validation feedback.

The page inventory remains unchanged; Settings is still the same existing sidebar page.

## Settings backend

A new `src/core/settings/` service stores non-sensitive preferences as per-user JSON with:

- cross-platform user configuration locations;
- schema-tagged settings payloads;
- atomic writes;
- validation before explicit saves;
- safe fallback to baseline defaults when an existing settings file is malformed;
- runtime last-page, last-folder, and window-geometry convenience state;
- explicit exclusion of account/provider credentials.

Default values preserve `v1.0.0.1` behavior until the user changes a setting.

## Existing runtime integration

Settings are wired only into existing application actions:

- startup navigation;
- close/delete/clear confirmation points;
- Live Logs rendering and retention;
- provider-load/customer-import/report-export/log-export file dialog starting directories;
- normal window geometry save/restore.

No provider network behavior, invoice sending, account reservation, task threading, domain model, or provider manifest contract changes are included.
