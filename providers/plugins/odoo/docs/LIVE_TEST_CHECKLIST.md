# Odoo Live Test Checklist

## 1. Odoo prerequisites

Confirm the API user can:

- authenticate through the external API;
- read/create `res.partner`;
- read `res.country` and `res.currency`;
- create/read/post `account.move` customer invoices;
- create/read/execute `account.move.send.wizard`;
- read `mail.message`, `mail.notification`, and `mail.mail` if provider-side evidence is required;
- use a correctly configured outgoing Odoo mail server.

Use an Odoo plan/database where External API access is available.

## 2. Account canary

In Invio:

1. Providers → load `provider.json` and approve the trusted executable adapter.
2. Accounts → Add Account → Odoo.
3. Enter Base URL, Database, Username/Email, API Key.
4. Run API Test.

Expected: `Odoo API connection verified.`

## 3. One-recipient Task

Prepare:

- one customer email you control;
- explicit Name and two-letter Country (email-only import on current Invio can materialize defaults);
- a simple USD template;
- Invoice Type `INVOICE`;
- default title `Invoice`;
- blank subtitle;
- Automatic Tax OFF;
- all line taxes 0;
- Footer/Customer Note/Terms empty;
- Customer Reuse ON for the normal search-or-create flow.

Run one Task.

## 4. Required acceptance evidence

Verify all of the following:

- Invio Task result;
- Invio Live Logs;
- Invio Reports provider customer/invoice evidence;
- Odoo customer record;
- Odoo invoice exists;
- Odoo invoice state is Posted;
- correct invoice amount/currency/due date;
- Odoo invoice PDF exists/generated by send workflow when supported;
- Odoo mail evidence is Sent or Queued where readable;
- recipient inbox receives the invoice email.

Provider `SENT` or `QUEUED` evidence is not the same as inbox delivery.

## 5. Failure rule

If the first canary fails, do not run bulk recipients. Save:

- complete relevant Invio Live Logs;
- Task screenshot;
- Reports recipient row;
- Odoo invoice/customer screenshots;
- exact Odoo server error (redact API keys/cookies).

If Invio reports an **Uncertain** external mutation, inspect Odoo before starting another full Task to prevent duplicate invoices or emails.
